# 讓 AI 幫你拍的影片自動上中英字幕（新手版）

自拍一支影片，對 Claude 說一句「幫這支影片上中英字幕」，它會聽寫你講的話、校對錯字、翻成英文。你確認一次之後，它會把字幕燒進畫面，交給你一支可以直接發 IG Reels 或 YouTube Shorts 的影片。

- **免費**：除了 Claude 本身的訂閱，所有工具都免費。
- **不上傳**：影片和聲音全程在你自己的電腦上處理。
- **你只做兩件事**：開口請它做，以及看一分鐘的字幕確認表。

---

## 開始前：確認你符合這三個條件

| 條件 | 為什麼需要 | 怎麼確認 |
|---|---|---|
| **Apple 晶片的 Mac**（M1、M2、M3、M4 以後） | 語音辨識工具 mlx-whisper 只能在 Apple 晶片上跑 | 左上角 蘋果選單 → 關於這台 Mac → 看「晶片」那一行 |
| **Claude 付費方案**（Pro 以上） | 要用 Claude Code 才能讓 AI 在你電腦上跑工具，免費方案不含 | 價格以 [Claude 官網](https://claude.com/pricing)為準 |
| **Claude 桌機版 App** | Claude Code 在 App 裡的「Code」分頁 | 從 [claude.com/download](https://claude.com/download) 下載 |

Windows 電腦、Intel 晶片的舊 Mac、只用網頁版或手機 App 的人，目前都用不了這套。

## 要下載的東西

總共五樣，你自己只要處理 Claude 桌機版和 Homebrew，其他三樣會在第一次使用時，由 Claude 檢查你缺什麼，問過你之後幫你裝。

| 東西 | 是什麼 | 誰來裝 | 大小／時間 |
|---|---|---|---|
| Claude 桌機版 App | 跟 AI 對話、讓它操作電腦的地方 | 你自己從 [claude.com/download](https://claude.com/download) 下載安裝 | 一般 App 大小 |
| Homebrew | Mac 上的免費軟體安裝工具，Claude 要靠它幫你裝 ffmpeg | 你自己裝一次（步驟在下面），已經裝過就跳過 | 要等一段時間 |
| ffmpeg | 免費的影片處理工具，負責把字幕燒進畫面 | Claude 幫你裝（透過 Homebrew） | 幾分鐘 |
| mlx-whisper | 免費的語音辨識工具，負責把聲音轉成文字 | Claude 幫你裝 | 幾分鐘 |
| 語音辨識模型 | mlx-whisper 用來「聽」的大腦 | 第一次聽寫時自動下載 | 約 1.5GB，只下載一次 |

**自己裝 Homebrew 的步驟**（Mac 沒裝過才需要，不確定的話 Claude 第一次會先幫你檢查）：

1. 按鍵盤的 `Command + 空白鍵`，輸入「終端機」，按 Enter，會打開一個可以打字的視窗。
2. 複製下面這一行，貼進終端機，按 Enter。這行指令來自 [Homebrew 官網](https://brew.sh/zh-tw/)首頁：

   ```
   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
   ```

3. 畫面出現 `Password:` 時，輸入你的電腦開機密碼，按 Enter。打字時畫面不會出現任何字，這是正常的。
4. 它會列出接下來要安裝的東西，停下來等你確認，這時再按一次 Enter。
5. 等它跑完，最後一行又可以打字就代表裝好了。最後出現的英文說明（Next steps）不用理，Claude 會幫你處理。
6. 回到 Claude，跟它說「Homebrew 裝好了」，剩下的它會接著幫你裝好。

## 第一次使用：安裝 skill

skill 是一個資料夾，裡面放著「怎麼上字幕」的說明書和工具程式。Claude 讀了它，就知道該怎麼一步步幫你做。

1. 打開 Claude 桌機版，切到上方的 **Code** 分頁。
2. 選一個資料夾開始對話，建議選你平常放影片的資料夾。
3. 把下面這句整句複製，貼給 Claude：

   ```
   幫我安裝這個 skill：https://github.com/evetsai0226/video-subtitles ，放到 ~/.claude/skills/video-subtitles/
   ```

   它要動你的電腦時會跳出確認，按「允許」。
4. 裝好之後，開一個新對話，skill 就會生效。

## 每次上字幕：五個步驟

1. **把影片放進資料夾**：放到 Claude Code 開著的那個資料夾，iPhone 拍的 `.MOV` 直接放進去就好，不用先轉檔。
2. **開口請它做**：「幫〈你的影片檔名〉上中英字幕」。iPhone 拍的影片，檔名通常是 IMG 加一串數字，例如 IMG_1234.MOV。只要中文字幕就說「只要中文」。
3. **按「允許」**：Claude 每次要在你電腦上跑工具，都會跳出確認，看到是跟字幕有關的就按允許。第一次用時它會先檢查工具，缺什麼會問你能不能裝。
4. **看確認表**：它會列出「秒數｜中文｜English」的表格，再把沒把握的地方單獨列出來，例如：「38 秒聽到 Rodström，我猜是 Nordstrom，對嗎？」你直接回「對」或告訴它正確的字就好。講錯的地方也可以請它刪掉。
5. **拿成品**：確認後它會燒錄，然後自己抽幾張畫面檢查字幕有沒有上去、有沒有擋到臉，檢查完才把成品交給你。成品存在原影片旁邊，檔名是 `原檔名-字幕版.mp4`，可以直接上傳 IG。

## 實際跑一次要多久（48 秒的 iPhone 4K 自拍影片）

| 步驟 | 時間 |
|---|---|
| 聽寫（模型已下載後） | 約 5 秒 |
| AI 校稿、翻譯、列確認表 | 1–2 分鐘 |
| 你看確認表 | 約 1 分鐘 |
| 燒錄成 1080×1920 | 約 2 分鐘 |

第一次使用要另外加上裝工具和下載模型的時間，大約 10–20 分鐘，視網速而定。這個時間是估計，還沒在全新的電腦上實測過。

## 常見問題

**語音辨識準嗎？**
一般的中文口語很準。最容易錯的是英文店名和人名，例如 Nordstrom 被聽成 Rodström。所以流程會讓你確認一次再燒錄。

**網頁版 Claude 可以做嗎？**
目前不行。Claude 本身聽不到聲音，要靠 Whisper 轉文字；網頁版的環境很難裝 Whisper，影片檔也往往超過上傳上限。

**字幕樣式可以改嗎？**
預設是白字黑描邊、不加底色，放在畫面約四分之三高的位置，避開 IG 底部的按鈕區。想改位置或大小，直接跟 Claude 說。

**橫式影片可以嗎？**
可以。橫式影片會輸出 1920×1080，字幕放在畫面下方。

**不想用 Claude 的話呢？**
Windows 使用者可以試 [VidScribe](https://github.com/AinxietyLab/VidScribe)，這是一個本機跑的免費字幕 App，自己拖影片進去、自己校稿。或者用任何工具先做出 `.srt` 字幕檔，再用剪映的「匯入本地字幕」上字幕，匯入這個功能是免費的。
